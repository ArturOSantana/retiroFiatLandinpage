# Retiro Fiat 2026

Landing page estática, pronta para publicação no GitHub Pages. Abra `index.html` localmente para visualizar.

## Trocar imagens e marcas

- Substitua `assets/arte-retiro.jpg` pela nova arte, mantendo o mesmo nome. Se mudar o nome, atualize as referências em `index.html`.
- Os logos usados são `logotipo_jovens_hor_branco.png` e `logopascom.png`, na raiz do projeto. Substitua esses arquivos mantendo os mesmos nomes (e formatos) para atualizar o cabeçalho e o rodapé.
- A página não depende de compilação ou servidor. No GitHub, habilite Pages para a branch e pasta desejadas.
